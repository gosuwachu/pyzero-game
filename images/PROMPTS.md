# Generated sprite prompts

Created with the built-in `image_gen` tool, one asset per call. No API key or generation tools are needed to play.

The prompts below record the final generation/edit call for each delivered sprite. `chest_open` used `chest` as its edit reference; `door_open` used `door`. The key’s final edit removed glow from its first generated version.

Preparation: crop transparent outer padding for freestanding objects, resize with nearest-neighbour sampling to a 32-pixel design grid, place on a transparent canvas, then enlarge exactly 2×. Door frames use the same 28 × 62 design-grid rectangle; chest variants have the same 26-pixel width and bottom baseline. Platform artwork fills a 32 × 8 rectangle at the top of its grid. Source DK artwork is not resized.
