# Sprite credits

This collection combines 20 DK book sprites with 14 generated objects. It is not a CC0 asset pack.

## DK book artwork

Source: DK’s [Computer Coding resources](https://dk.com/blogs/resources/computer-coding), the official companion resources for *Coding Games in Python / Computer Coding Python Games for Kids*.

[Original resource ZIP](https://res.cloudinary.com/dk-hub/raw/upload/v1530886539/Python_Games_Resource_Pack_3_ra4i7c.zip), downloaded 5 October 2026.

The files below are copied unchanged, apart from filenames. Their original dimensions and transparency are preserved. DK provides the pack for building the book’s games; the archive contains no standalone licence file. The original artwork remains credited to DK and its creators; no CC0 licence is claimed for it.
